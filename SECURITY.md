# Security Policy

## Supported version

The `main` branch is the supported version of Human Simple Frontstage.

## Reporting a vulnerability

Please do not post potential vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository when it is available. If that option is unavailable, email [thisaimentor10@gmail.com](mailto:thisaimentor10@gmail.com) with the subject line `Security report: Human Simple Frontstage`.

Include a clear description, affected files or behavior, steps to reproduce, and any suggested mitigation. You will receive an acknowledgement as soon as practical, followed by updates while the report is reviewed.
